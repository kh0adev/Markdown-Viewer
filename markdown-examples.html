# Machine Learning - Tuần 1

## Linear Regression

$$h_\theta(x) = \theta^T x$$

### Cost Function

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2$$

### Gradient Descent

Lặp lại cho đến khi hội tụ:

$$
\theta_j := \theta_j - \alpha \frac{\partial}{\partial \theta_j} J(\theta)
$$

## Code mẫu

```python
import numpy as np

def predict(X, theta):
    return X.dot(theta)
```

> **Ghi nhớ:** *Learning rate $\alpha$ quyết định tốc độ hội tụ.*

# Hướng dẫn cài đặt Docker

## Yêu cầu

- Docker >= 24.0
- Docker Compose >= v2.20

## Cài đặt

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install docker.io
sudo systemctl start docker
```

### macOS

Tải Docker Desktop từ [docker.com](https://docker.com).

## Cấu hình

Tạo file `docker-compose.yml`:

```yaml
version: '3.8'
services:
  web:
    image: nginx:alpine
    ports:
      - "80:80"
  db:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: secret
```

## Chạy

```bash
docker compose up -d
```

> [!TIP]
> Dùng `docker compose logs -f` để theo dõi log.

# Tối ưu thuật toán Neural Network

**Tác giả:** Khoa Trần¹, Anh Nguyễn²
¹ Đại học Bách Khoa, ² Đại học Công nghệ

## Abstract

Bài báo đề xuất phương pháp tối ưu mới giúp
tăng tốc độ huấn luyện lên **35%**.

## Phương pháp

Thuật toán đề xuất:

$$
\theta_{t+1} = \theta_t - \eta \cdot \frac{m_t}{\sqrt{v_t} + \epsilon}
$$

với $m_t$ và $v_t$ là moment bậc 1 và bậc 2.

|------------|----------|------------------|

| Adam       | 94.1%    | 95               |
| **Ours**   | **96.7%** | **78**           |
